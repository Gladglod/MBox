# 离线缓存（下载到本地）· 实现说明

> 用户使用方法见根目录 `README.md` 的「离线缓存」一节，本文记录实现细节与代码位置。

文件存放在 `Android/data/{包名}/files/download/`（应用专属目录，无需存储权限）。

## 缓存抽屉（入口 1）

详情页头部剧名右侧「缓存」chip（挨着收藏星标与换源），弹出 **iOS 玻璃质感半屏底部抽屉**
（**View 级动效**：蒙层淡入 + 面板自底部带回弹滑入，关闭时面板下沉 + 蒙层淡出，
上半屏播放预览区不被遮挡），选集以**一行 5 个的圆角小方块网格**展示（点选 = 品牌色填充，
已缓存的集置灰带勾角标不可重复选），支持全选；抽屉材质与文字随日/夜主题翻色。

## 下载引擎（`download/DownloadManager`）

- 自动把详情页保存的选集页面地址解析成真实媒体地址（复用各源 spider / 采集接口）；
  需要二次解析的集会尝试配置的 **type=1 JSON 解析接口**（与在线播放的解析线路对齐），
  仍拿不到直链（纯网页嗅探）才提示「暂不支持离线缓存」；`video://` 前缀视为真实媒体地址直接下载；
- **类型探测**：下载前用响应头 Content-Type + 响应体开头（`#EXTM3U`）判断真实类型，
  文件按真实扩展名命名——直链 `.mp4/.mkv/.flv…`、fMP4 的 m3u8 → `.mp4`、纯 TS 的 m3u8 → `.ts`，
  不再一律 `.ts`；
- **m3u8 / HLS**：多级 master playlist、AES-128 密钥解密（含无 IV 按序号推导）、
  `EXT-X-BYTERANGE` 子范围分段、分段并发下载、失败重试、分段文件落盘 → **断点续传**，
  全部完成后合并为单个文件并清理临时分段；
  检测到直播流（无 `#EXT-X-ENDLIST`）或 SAMPLE-AES 加密会明确报错不支持；
  可选 **m3u8 去广告**（设置开关 + 大站豁免，与在线播放一致）；
- **直链文件**：Range 断点续传，下载完成自动改回正式文件名；
- 任务队列最多同时 2 个，进程被杀后重启自动把「下载中」任务恢复为「已暂停」，点继续即可续传。

## 前台服务

`DownloadService`：下载期间通知栏保活显示，无任务时自动停止。

## 任务列表（`DownloadActivity`）

与播放历史页同套 iOS 玻璃卡片交互：缩略图 + 剧名/集数 + 进度条与状态；
下载中实时显示 **已下载/总大小 与速度（KB/s）**，已完成显示文件大小。

## 离线播放（`LocalPlayActivity`）

直接复用项目自带的 **`VodController`**，与在线播放同一套控制条，
内核跟随「播放设定」的 IJK / EXO / 解码方式 / 渲染 / 画面比例。
支持**播放进度记忆**（下次打开自动跳到上次位置）、
**全屏切换**（横竖屏自动切换，宽>高视频自动进横屏）、播放失败**静默重试一次**（之后提示文件可能损坏）、
同剧**多集连播**（播完自动下一集，点击任务即从该剧全部已缓存集数进入连播）。

## 数据库

v1 → v2：新增 `downloadRecord` 表（`AppDataManager.MIGRATION_1_2`），任务状态与进度实时落库，
UI 通过 EventBus `DownloadEvent` 增量刷新。
