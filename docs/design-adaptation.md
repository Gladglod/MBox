# 适配说明 · 实现细节

> 面向开发者的适配与性能细节记录。

## AutoSize

设计基准：竖屏按 **360dp** 宽；横屏按 `360 × 屏宽/屏高` 折算，保证横竖屏 density 一致，
避免横屏下 UI 被整体放大。

## 内存

分类列表（`GridFragment`）在页面滑走时释放视图与数据，滑回时重建，
避免多 Tab 常驻导致内存溢出。

## 弹幕搜索对话框

自适应屏幕：限宽 `min(90% 屏宽, 430dp)`、限高 `min(86% 屏高, 560dp)`。

## 数据源地址页

「我的 → 数据源地址」已改为独立页面，不再使用 `dialog_api` 弹窗；
该弹窗本身也重排成竖排（二维码 110dp 居中在上 + 地址 + 历史直播/存储权限 + 点播/直播地址 + 确定，288dp 宽），
仅旧的 TV 设置页还在用。

## 背景

背景优先级：自定义配图（`files/wp`）> 纯色（`HawkConfig.WALLPAPER_COLOR`）> 默认 `app_bg`。
设置页里选完立即生效（`BaseActivity.applyWallpaperNow()`），其他页面在 `onResume` 时自动跟随。
