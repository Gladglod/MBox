# 「我的」页面 · 实现说明

> 用户使用方法见根目录 `README.md` 的「我的」一节，本文记录实现细节与代码位置。

## 整体结构

- 整页是一个**条状菜单**（`item_user_menu`，52dp 一行，左侧图标 + 标题 + 右侧当前值 + `›` 箭头），
  不再是横向滑动的卡片入口；「热门推荐」「直播 / 推送」快捷入口以及搜索入口均已移除（搜索仍在首页顶部）。
- 所有二级页面共用同一套手机端设置行样式（`MineSettingActivity` + `item_mine_setting_row`），
  通过 `EXTRA_SECTION` 参数区分分组，不再是 TV 端的左栏 + ViewPager。

## 菜单项实现要点

- **数据源地址**：独立页面（`ApiSettingActivity`，不再是 `dialog_api` 弹窗）。
  该弹窗本身也重排成竖排（二维码 110dp 居中在上 + 地址 + 历史直播/存储权限 + 点播/直播地址 + 确定，288dp 宽），
  仅旧的 TV 设置页还在用。切换地址后自动清缓存并重启应用。
- **外观主题**：自定义配图压缩后存 `files/wp`。
- **继续观看**：不再是独立区块，而是挂在**「播放历史」这一行下面的子模块**：
  一排 **84dp 小方块**（海报 + 剧名 + 底部进度线），横向滑动（最多 12 条），点击直接进详情页；没有观看记录时整块隐藏。

## 播放历史 / 收藏

- 条目卡统一换成 **iOS 玻璃卡片**（16dp 圆角、半透明填充 + 高光描边，日夜色随 `values-night` 自动切换）。
- 左滑整体藏在卡片内部：**弹簧收摊 + 快滑甩开判定**，按钮是级联浮现的玻璃胶囊（置顶 / 删除），
  关闭系统「移除动画」时全部降级为直接置位。**播放历史长按 = 直接进入编辑模式并勾选该条**。

## 背景与壁纸

背景优先级：自定义配图（`files/wp`）> 纯色（`HawkConfig.WALLPAPER_COLOR`）> 默认 `app_bg`。
设置页里选完立即生效（`BaseActivity.applyWallpaperNow()`），其他页面在 `onResume` 时自动跟随。
