# MBox（手机竖屏版）

基于 [TVBoxOS](https://github.com/q215613905/TVBoxOS) 改造的 **手机竖屏** 视频客户端。
本仓库在原生 TV 交互之上重做了首页布局与详情页结构，并把整个界面（播放器、直播页、历史 / 收藏、设置）统一成手机触摸风格。

## 构建与安装

```bash
# Windows
gradlew.bat :app:assembleJava64Debug
```

产物：`app/build/outputs/apk/java64/debug/TVBox_debug-java64.apk`

也可以直接到 [Releases](https://github.com/Gladglod/MBox/releases) 下载对应机型的安装包（java / java32 / java64 等版本）。

## 快速上手

### 首页

顶部是「分类页签 + 分页内容」的横向结构，页签左侧第一项固定为 **热门推荐**，也是启动应用后默认停留的页面。

- **左上角是假搜索框**：整块可点，进入搜索页。
- **右上角是数据源胶囊**：显示当前站点名，点开即可切换数据源；只有一个站点时不可点。
- **热门推荐**：网格展示当前数据源的推荐内容；可在「我的 → 界面偏好 → 首页推荐」改为显示观看历史。
  没有推荐内容时会自动回退到本地观看历史，历史也为空时提供「换个数据源」按钮。
- **首页标签可自定义**：「我的 → 界面偏好 → 首页标签」中勾选想在首页显示的分类，长按可拖动调整顺序，
  支持全选 / 全不选 / 恢复默认。
- **左右滑动**切换页面，顶部页签同步跟随。

### 详情页与播放

进入详情页后，播放器内嵌在页面顶部随内容滚动：

- **点击预览区域**：显示 / 隐藏播放控制组件（不会自动进入全屏），首次点击会先拉起播放。
- **头部**：剧名右侧依次是 **收藏星标**（点击收藏 / 取消）、**换源**胶囊、**缓存**入口。
- **选集**：单行横滑，右侧可一键切换「正序 / 倒序」。
- **页面底部**：「其他信息」与「内容简介」两个折叠块，点「详情 ▾」展开。

### 播放器控制条

主按钮行（从左到右，等宽均分）：

| 按钮 | 说明 |
| --- | --- |
| 播放 / 暂停 | 单击切换 |
| 下一集 | 长按弹出选集 |
| 弹幕 | 纯开关，开启时文字变青色并显示「弹幕开」 |
| 倍速 | 弹出倍速选项 |
| 全屏 | 进入 / 退出全屏 |

右上角：**投屏** + **圆形「⋮」菜单**。

全屏与退出：

- **全屏按钮**：进入全屏（横屏铺满）；再点一次退出全屏回到详情页。
- **左上角退出按钮**：全屏状态下退出全屏；非全屏状态下（详情页内嵌播放）退出当前播放。

### 播放手势

| 手势 | 行为 |
| --- | --- |
| 单击 | 显示 / 隐藏控制条 |
| 双击中间 30% | 播放 / 暂停（可在「播放手势」关闭） |
| 双击左侧 35% | 后退（默认 3 秒，可设为 3 / 5 / 10 秒） |
| 双击右侧 35% | 前进（同上） |
| 长按后左右滑动 | 调节倍速（右滑加速、左滑减速，松手恢复；最高倍速可设为 2.0X / 3.0X / 4.0X） |
| 横向滑动 | 拖动进度 |
| 左半屏纵向滑动 | 调节亮度 |
| 右半屏纵向滑动 | 调节音量 |
| 竖屏上下滑动 | 切换上一集 / 下一集（顶部临时显示标题，可在「播放手势」关闭） |

> 长按加速、双击、竖屏滑动均可在「我的 → 播放手势」中关闭。

### 「⋮」设置抽屉

横屏从右侧滑出，竖屏从底部滑出，包含：

1. **播放器 / 解码 / 画面比例**：内联下拉选择。
2. **片头片尾**：点击记录当前位置；长按后左右滑动微调；旁边是重置按钮。
3. **弹幕设置**：弹幕颜色、速度、字号、行数、透明度，以及「搜索弹幕」入口。
4. **其他**：播放重试 / 刷新、字幕、音轨、视频轨、横竖屏切换、屏显开关、解析线路。

## 直播

竖屏时页面分上下两部分：上方 16:9 播放器，下方是**常驻频道面板**；进入横屏全屏后面板隐藏、播放器铺满。

- 顶部一排**分类标签**（央视 / 卫视 / 各省频道……），点选切换分组。
- 下方是频道列表：上行是频道名，下行自动显示**正在直播的节目**；点击切台。
- 面板底部三个入口：

| 入口 | 行为 |
| --- | --- |
| 节目单 | 本频道 7 日节目列表，支持时移 / 回看；返回键先退回频道列表 |
| 设置 | 播放源（线路）/ 画面比例 / 播放器 / 超时 / 直播地址历史等设置抽屉 |
| 全屏 | 进入横屏全屏；返回键先退出全屏 |

## 我的

底部导航第 4 项，是一个条状菜单：

| 菜单项 | 内容 |
| --- | --- |
| 数据源地址 | 独立页面：点播 / 直播地址输入、本地配置文件导入、存储权限、扫码导入（二维码 + 局域网地址）、历史配置列表（点一条即切换、可删除、可清空）。切换地址后自动重启应用 |
| 外观主题 | 自定义配图、数据源壁纸、重置背景、纯色背景（12 个深色预设）、首页多行、搜索展示样式、启动页 |
| 播放历史 | 条状列表：缩略图 + 集数角标 + 剧名 + 进度条。左滑露出「置顶 / 删除」；右上角「编辑」进入多选批量删除。历史行下方是「继续观看」小方块，点击直接续播 |
| 收藏 | 与播放历史同一套列表样式，支持左滑置顶/删除与编辑多选 |
| 播放设定 | 播放器、渲染方式、画面缩放、解码方式、缓存、自动换线、M3U8 去广告、窗口预览 |
| 界面偏好 | 首页标签、首页推荐来源、聚合搜索、历史合并、历史记录数量、嗅探 WebView、调试模式 |
| 播放手势 | 长按加速开关与最高倍速、双击中间暂停、双击快进/快退秒数、竖屏上下滑切集 |
| 弹幕设定 | 弹幕开关、自定义接口 + 一键测试、最大行数、速度、透明度、字号、随机颜色 |
| 媒体库 → 离线缓存 | 打开缓存任务列表 |
| 关于 | 应用信息、检查更新 + 自动检查开关、配置地址、设备与系统版本、项目来源 |

## 离线缓存（下载到本地）

把选集视频真正存进手机（应用专属目录，无需存储权限）：

- **入口 1**：详情页头部剧名右侧的「缓存」胶囊，弹出半屏抽屉，选集以小方块网格展示（支持全选，已缓存的集不可重复选）。
- **入口 2**：「我的 → 媒体库 → 离线缓存」，打开缓存任务列表。

缓存任务列表中：

- 下载中实时显示 **已下载大小与速度**，已完成显示文件大小；
- **点击** = 播放（已完成）/ 暂停·继续（未完成）；**长按** = 批量编辑（全选 / 批量删除）；**左滑** = 删除单个任务（连缓存文件一起清理）。

已完成的缓存支持直接播放：与在线播放同一套控制条和手势，自动记忆播放进度、多集连播、横竖屏自适应。

## 检查更新

走 GitHub Releases，不依赖第三方更新服务：

- **手动检查**：「我的 → 关于 → 检查更新」。
- **自动检查**：启动应用后静默请求一次，24 小时内最多一次，发现新版才弹窗；开关在「关于 → 启动时自动检查」。
- 可对某个版本选择「忽略此版本」，自动检查不再提示（手动检查仍会显示）。
- 下载完成自动拉起系统安装器；Android 8.0+ 需先授予「安装未知应用」权限。
- GitHub 连不上时，弹窗提供「浏览器打开」，可直接到 Releases 页面手动下载。
