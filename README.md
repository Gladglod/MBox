# MBox（手机竖屏版）

基于 [TVBoxOS](https://github.com/q215613905/TVBoxOS) 改造的 **手机竖屏** 客户端（纯 XML + Java，无 Compose，包名 `com.github.tvbox.osc`）。
本仓库在原生 TV 交互之上重做了首页布局与详情页结构，并把整个界面（播放器、直播页、历史 / 收藏、设置）统一成手机触摸风格。

## 构建

```bash
# Windows
gradlew.bat :app:assembleJava64Debug
```

产物：`app/build/outputs/apk/java64/debug/TVBox_debug-java64.apk`

## 首页

顶部是「分类页签 + 分页内容」的横向结构，页签左侧第一项固定为 **热门推荐**，也是启动应用后默认停留的页面。

### 顶栏

顶栏只做两件事，**没有页面标题**——紧挨着的页签条已经在指示"当前在第几页"，再叠一行同名标题是重复：

- **左：假搜索框**（`searchBar`）。整块可点，进搜索页；首页不抢键盘焦点，真输入框留给搜索页。
- **右：数据源胶囊**（`tvMenu`）。文字就是当前站点名（不再是「换源」这种行话），点开切换；
  只有一个站点时自动去掉箭头并置为不可点，避免做成死按钮。
- 切源期间胶囊轻微呼吸（`startSourceChipBlink()`），替代原来那行每秒刷新的日期。
  手机上状态栏自带时间，那个 `yyyy/MM/dd E HH:mm` 是 TV 版遗留，已移除。

### 内容

- **热门推荐**（`HotRecommendFragment`）：网格展示首页接口返回的推荐列表（`AbsSortXml.videoList`）；
  当「界面偏好 → 首页推荐」选成「历史记录」时改读本地播放记录（最多 30 条，带「上次看到 x 集」）。
  列表按批追加：首批 12 条，滑到底再补 12 条，不会一进首页就把几十张海报一次性丢给 Glide。
  - **空推荐兜底**：不少数据源的 `homeContent` 根本不返回推荐列表，此时自动退回本地观看历史，
    避免默认落地页是一片「暂无推荐内容」；历史也为空时才显示提示文案 + 一个「换个数据源」按钮
    （`HomeActivity.onHomeEmptyAction()`：可切站点多于 1 个就弹列表，否则直接进数据源地址页）。
  - **间距**：与分类页共用 `GridSpacingItemDecoration(8dp)`，落地页不再是 0dp 紧贴。
  - **标题两行**：`item_grid` 的 `tvName` 允许 2 行，中文长片名不再被截成一个省略号。
- **加载态是骨架屏不是转圈**（`HomeSkeletonCallback` + `loadsir_home_skeleton`）：
  LoadSir 挂在内容区而不是顶栏，骨架按真实网格尺寸先占位（页签条 44dp + 三列海报位），
  数据回来后原地替换，不会整块跳一下。
- **标签可编辑**：「我的 → 界面偏好 → 首页标签」（`HomeTabSettingActivity`）
  - 勾选决定某个分类是否出现在首页，**长按拖动**调整顺序，底部有「全选 / 全不选 / 恢复默认」。
  - 配置存 `HawkConfig.HOME_TABS`（每行 `可见(1/0)\t分类id`，行序即页序），换数据源后新增的分类会自动追加到末尾并默认显示。
  - 保存返回后首页在 `onResume` 里检测到配置变化，重建页签与页面，无需重启。
- **左右滑动**切换页面时顶部页签会同步跟随；从「分类」页点某个分类会跳到首页对应页签。


## 详情页

- **预览播放器**：进入详情页后播放器内嵌在页面顶部，随内容滚动做位移；不再自动滚动到选集区，进入即停在页面最顶部。
- **点击预览区域**：只**显示/隐藏播放组件**（退出、投屏、菜单、播放/暂停、下一集、弹幕、倍速、全屏），**不会**自动进入全屏。首次点击会先拉起播放。
- **预览热区**：`previewPlayerBlock` 是盖在播放器上的透明热区，控制条显示时自动隐藏，避免挡住控制条按钮。
- **选集**：单行横滑，右侧「正序 / 倒序」一键切换排序。
- **头部只留三样**：海报 + 剧名 + **收藏星标 + 换源 chip**——星标在剧名右侧，`★`（已收藏，品牌青）/
  `☆`（未收藏，灰）一键切换，点亮时带 1.25× 缩放脉冲反馈；换源是剧名旁的玻璃胶囊 chip，不再是独立大按钮。
  （原「立即播放 / 搜索 / 简介」按钮已整体移除。）
- **信息区移到页面底部**，拆成两个独立折叠容器：
  - **其他信息**：来源、年份常驻；地区 / 语言 / 演员 / 导演收进折叠块，靠下面一行「详情 ▾」开关展开（箭头旋转 180°）；
  - **内容简介**：独立容器 + 自己的「详情 ▾」折叠，溢出时才显示开关。
  - 换源 / 重新加载后两个容器都会自动收回折叠态；「类型」字段已删除。

## 播放器控制条

主按钮行（从左到右，等宽均分）：

| 按钮 | 说明 |
| --- | --- |
| 播放 / 暂停 | 单击切换 |
| 下一集 | 长按弹出选集 |
| 弹幕 | 纯开关，开启时文字变青色并显示「弹幕开」 |
| 倍速 | 弹出倍速选项 |
| 全屏 | 进入 / 退出全屏 |

右上角：**投屏** + **圆形「⋮」菜单**。

### 全屏与退出

- **全屏按钮**：进入全屏（横屏铺满，隐藏系统状态栏/导航栏）；再点一次退出全屏回到详情页。
- **左上角退出按钮**：
  - **全屏状态下** → 退出全屏，回到详情页；
  - **非全屏状态下**（详情页内嵌播放）→ 退出当前播放（离开详情页）。

### 手势

| 手势 | 行为 |
| --- | --- |
| 单击 | 显示 / 隐藏控制条 |
| 双击中间 30% | 播放 / 暂停（可在「播放手势」关闭） |
| 双击左侧 35% | 后退（默认 3 秒，可设为 3 / 5 / 10 秒） |
| 双击右侧 35% | 前进（同上） |
| 长按后左右滑动 | 调节倍速（右滑加速、左滑减速，0.5X ~ 最高倍速，松手恢复；最高倍速可设为 2.0X / 3.0X / 4.0X） |
| 横向滑动 | 拖动进度 |
| 左半屏纵向滑动 | 调节亮度 |
| 右半屏纵向滑动 | 调节音量 |
| 竖屏上下滑动 | 切换上一集 / 下一集（顶部临时显示标题，可在「播放手势」关闭） |

> 长按加速、双击、竖屏滑动均可关闭；

### 「⋮」设置抽屉

- **横屏**：从右侧向左滑出；
- **竖屏**：从底部向上滑出。

抽屉内容：

1. **播放器 / 解码 / 画面比例** —— 内联下拉列表（不再用系统 `PopupMenu`，尺寸与配色跟随抽屉）。
2. **片头片尾** —— 点击记录当前位置；长按后左右滑动微调（每 14dp = 1 秒）；旁边是重置按钮。
3. **弹幕设置** —— 当前在线弹幕源名称、弹幕颜色、速度、字号、行数、透明度，以及「搜索弹幕」入口。
4. **其他** —— 播放重试 / 刷新、字幕、音轨、视频轨、横竖屏切换、屏显开关、解析线路。

## 直播页

竖屏骨架与详情页一致：**上：16:9 播放器，下：常驻频道面板**；横屏全屏时面板藏掉、播放器撑满，控制条贴屏底。

### 频道面板（常驻）

- 顶部一排**分类 chip**（央视 / 卫视 / 各省频道……，来自直播配置的分组），选中态用强调色描边，
  和剧集页「播放源」同一套语言。
- 下方是**单列玻璃频道行**（播放历史同款卡片材质，16dp 圆角）：
  - 上行是频道名，下行自动显示**正在直播的节目**（`20:00-21:00  新闻联播`）；
  - EPG 没到的行第二行自动隐藏，不影响选择；选中行的频道名 / 节目变品牌青色。
  - 点行切台；切回面板时当前频道自动滚到可见并高亮。

### 「正在直播」节目预取

分类数据刷新后，**单线程串行**排队请求该分类下每个频道的 EPG（不是一次并发几十个请求把源打爆）：

- 复用节目单同一套解析：JSON / XMLTV 双格式、多备用查询名（台标名 → 规范化频道名 → 原名）逐个重试，
  自定义源全部查不到时自动用兜底地址（`epg.51zmt.top` diyp 接口）再试；
- **XMLTV 地址优化**：一份 XMLTV 节目单覆盖全部频道，整个分类只拉一次，每个频道各自解析出自己的段落；
- 结果按「频道名｜日期」缓存一天，反复切分类不重复请求；
- **generation 代次失效**：切分类或退出直播页后，排队中的旧批次结果直接作废，不进 UI、不串台；
- EPG 地址默认 `epg.51zmt.top` 的 diyp 接口，支持自定义（`HawkConfig.EPG_URL` / 直播配置里的 `epg` 字段）。

### 面板操作

| 入口 | 行为 |
| --- | --- |
| 底部「节目单」 | 本频道 7 日节目列表（左侧日期竖排 + 节目单），支持时移 / 回看（频道流含回看源时节目条目可点回播）；返回键先退回频道列表 |
| 底部「设置」 | 播放源（线路）/ 画面比例 / 播放器 / 超时 / 直播地址历史等设置抽屉，滑出方向与播放器设置抽屉一致 |
| 底部「全屏」 | 进入横屏全屏；返回键先退出全屏 |

## 「我的」页面

底部导航第 4 项。整页是一个**条状菜单**（`item_user_menu`，52dp 一行，左侧图标 + 标题 + 右侧当前值 + `›` 箭头），
不再是横向滑动的卡片入口；「热门推荐」「直播 / 推送」快捷入口以及搜索入口均已移除（搜索仍在首页顶部）：

| 菜单项 | 内容 |
| --- | --- |
| 数据源地址 | 进入**独立页面**（`ApiSettingActivity`，不再是弹窗）：点播 / 直播地址输入、「本地点播配置 / 本地直播配置」文件导入、存储权限、扫码导入（二维码 + 局域网地址）、**历史配置列表**（最新在前，标「当前」，点一条即切换、右侧图标或长按删除、右上角可清空）。切换地址后自动清缓存并重启应用 |
| 外观主题 | **自定义配图**（相册选图，压缩后存 `files/wp`）、数据源壁纸、重置背景、**纯色背景**（12 个深色预设圆点，选中带白边）、首页多行、搜索展示样式、启动页 |
| 播放历史 | 进入播放历史页，条目为**条状列表**：左侧缩略图 + 右上角「3/12」集数角标，右侧剧名、来源、观看进度条与「已看 x / y 集 · 百分比」。**左滑**露出「置顶 / 删除」；右上角「编辑」进入多选，底部条为「全选 / 删除(n) / 完成」 |
| 收藏 | 与播放历史同一套**条状 UI**：缩略图 + 剧名 + 来源 + 收藏时间，同样支持左滑置顶/删除与编辑多选 |
| 播放设定 | 播放器、渲染方式、画面缩放、IJK 解码方式、IJK 缓存、自动换线、M3U8 去广告、窗口预览 |
| 界面偏好 | **首页标签**（选择首页显示哪些分类、长按拖动排序）、首页推荐来源、聚合搜索、历史合并、历史记录数量、嗅探 WebView、调试模式 |
| 播放手势 | 长按加速开关与最高倍速、双击中间暂停、双击快进/快退秒数、竖屏上下滑切集 |
| 弹幕设定 | 弹幕开关、**自定义接口 + 一键测试**、最大行数、速度、透明度、字号、随机颜色 |
| 关于 | 应用名、版本号、包名、构建类型、**检查更新 + 启动自动检查开关**、首页数据源、配置地址、直播配置、弹幕接口、设备与系统版本、项目来源 |

- 「继续观看」不再是独立区块，而是挂在**「播放历史」这一行下面的子模块**：一排 **84dp 小方块**（海报 + 剧名 + 底部进度线），
  横向滑动（最多 12 条），点击直接进详情页；没有观看记录时整块隐藏。
- 播放历史 / 收藏的条目卡统一换成 **iOS 玻璃卡片**（16dp 圆角、半透明填充 + 高光描边，日夜色随 `values-night` 自动切换）。
  左滑整体藏在卡片内部：**弹簧收摊 + 快滑甩开判定**，按钮是级联浮现的玻璃胶囊（置顶 / 删除），
  关闭系统「移除动画」时全部降级为直接置位。**播放历史长按 = 直接进入编辑模式并勾选该条**。
- 弹幕「搜索弹幕」选中结果后对话框**立即关闭**，弹幕在后台继续加载完成，只弹一条提示，不再卡着搜索浮层看转圈。
- 所有二级页面共用同一套手机端设置行样式（`MineSettingActivity` + `item_mine_setting_row`），通过 `EXTRA_SECTION` 参数区分分组，不再是 TV 端的左栏 + ViewPager。
- 首页左上角的站点名称现在**只是文字**，点击不再跳转设置页（设置入口统一收归本页）。

## 版本更新（GitHub Releases）

走 GitHub Releases，不依赖任何第三方更新服务，仓库地址硬编码在 `UpdateChecker.REPO`
（`https://github.com/Gladglod/MBox`）。

- **入口**：「我的 → 关于 → 检查更新」，行右侧显示当前版本，点击后变成「检查中… → 已是最新 / 发现 x.y.z / 检查失败」。
- **自动检查**：启动首页后延迟 3 秒静默请求一次 `/releases/latest`，**24 小时内最多一次**（`HawkConfig.UPDATE_LAST_CHECK` 节流），
  只有真的发现新版才弹窗；开关在「关于 → 启动时自动检查」，关掉后只剩手动检查。
- **版本比较**：拿 release 的 `tag_name` 和本地 `versionName` 做**逐段数字比较**（`2.0.10 > 2.0.9`，`v2.0.1` 与 `2.0.1` 等价），
  相等或更旧都算「已是最新」。所以**发版时 `app/build.gradle` 的 `versionName` 必须和 tag 一致**，否则会误判。
- **选包**：按当前构建的 `BuildConfig.FLAVOR` 精确匹配 `MBox_release-<flavor>.apk`
  （java / java32 / java64 / python…），匹配不到再按设备 ABI 退一步，最后退到任意 `.apk`；
  都没有就提示「该版本没有提供与当前设备匹配的安装包」，主按钮变成「浏览器打开」。
- **下载与安装**：下到 `getExternalCacheDir()/update/`（已完整下载过的包直接复用，不重复消耗流量），
  弹窗内显示进度百分比；下载完自动拉起系统安装器，走 `FileProvider`（`${applicationId}.fileprovider`）。
  Android 8.0+ 若没给「安装未知应用」权限，会先跳到系统授权页，返回后再点「安装」即可。
- **忽略此版本**：把 tag 记进 `HawkConfig.UPDATE_IGNORE_TAG`，自动检查不再提示该版本，手动检查仍然会显示。
- **失败兜底**：GitHub API 连不上（国内网络常见）时弹窗提供「浏览器打开」，直接跳 Releases 页面手动下载。

发版时建议的上传约定（与代码里的选包逻辑对应）：

| 构建产物 | Release 里的文件名 |
| --- | --- |
| `MBox_release-java.apk` | java 版（arm32 + arm64 合一） |
| `MBox_release-java32.apk` | java32 版 |
| `MBox_release-java64.apk` | java64 版 |

## 适配说明

- AutoSize 设计基准：竖屏按 **360dp** 宽；横屏按 `360 × 屏宽/屏高` 折算，保证横竖屏 density 一致，避免横屏下 UI 被整体放大。
- 分类列表（`GridFragment`）在页面滑走时释放视图与数据，滑回时重建，避免多 Tab 常驻导致内存溢出。
- 弹幕搜索对话框自适应屏幕：限宽 `min(90% 屏宽, 430dp)`、限高 `min(86% 屏高, 560dp)`。
- 「我的 → 数据源地址」已改为独立页面，不再使用 `dialog_api` 弹窗；该弹窗本身也重排成竖排
  （二维码 110dp 居中在上 + 地址 + 历史直播/存储权限 + 点播/直播地址 + 确定，288dp 宽），仅旧的 TV 设置页还在用。
- 背景优先级：自定义配图（`files/wp`）> 纯色（`HawkConfig.WALLPAPER_COLOR`）> 默认 `app_bg`。
  设置页里选完立即生效（`BaseActivity.applyWallpaperNow()`），其他页面在 `onResume` 时自动跟随。
